## Stack

- [Next.js](https://nextjs.org) — framework
- [React](https://reactjs.org) — UI library
- [linaria](https://linaria.dev) — styles
- [TypeScript](https://www.typescriptlang.org) — type checking
- [ESLint](https://eslint.org) — linting
- [artginzburg/next-with-linaria-starter](https://github.com/artginzburg/next-with-linaria-starter) — project template
- [Vercel](https://vercel.com) — deploying
- [Google Sheets](https://sheets.google.com) — improvised CMS
